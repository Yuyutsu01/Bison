# Phase 01: Event-Driven Backtesting Engine & Glassmorphic Dashboard

## 📌 Executive Summary

Phase 01 delivers the foundation of **Bison**, an institutional-grade algorithmic trading platform. It establishes an end-to-end event-driven backtesting pipeline paired with an interactive Next.js 14 web application featuring a visual strategy builder and performance analytics dashboard.

---

## 💡 Core Concepts & Architecture

### 1. Event-Driven Architecture
Unlike vectorised backtesters which compute returns using array operations, an event-driven backtester models real-market event streams sequentially:
- **`MarketDataEvent`**: Emitted when a new market bar (timestamp, OHLCV data) arrives.
- **`SignalEvent`**: Emitted by a strategy when market conditions trigger a BUY or SELL signal.
- **`OrderEvent`**: Generated by the portfolio/order management system (OMS) specifying order type, quantity, direction, and ticker.
- **`FillEvent`**: Emitted when the execution handler/simulated broker fills an order.
- **`PortfolioEvent`**: Triggered after portfolio balances and position metrics update.

### 2. Zero Look-Ahead Bias
To eliminate forward-looking bias, signals calculated on bar $t$ (using closing prices up to bar $t$) generate orders that execute strictly on bar $t+1$'s **Open** price.

### 3. Realistic Market Friction Models
- **Commission Fee**: Fixed dollar cost charged per executed trade.
- **Slippage**: Basis point (bps) penalty applied to execution prices to simulate market impact and spread.

## 🛠️ Components Completed in Phase 01

### A. Backend Core (Python & FastAPI)
- **`app/core/events.py`**: Strong data models (`dataclass`) for all market and system events.
- **`app/core/event_bus.py`**: Synchronous event distribution queue routing events to registered handlers.
- **`app/data/handler.py`**: CSV market data loader with historical data for **SPY**, **AAPL**, and **MSFT**.
- **`app/strategies/ma_crossover.py`**: Moving Average Crossover strategy implementing the abstract `Strategy` interface.
- **`app/backtest/portfolio.py`**: Order management system tracking cash balances, positions, mark-to-market equity, and trade execution logs.
- **`app/backtest/metrics.py`**: Quantitative analytics calculation module:
  - Total Return (%)
  - Annualized Return (%)
  - Sharpe Ratio (annualized using 252 risk-free days)
  - Maximum Drawdown (%)
  - Win Rate (%)
  - Profit Factor
  - Total Trade Count
- **`app/backtest/engine.py`**: Main backtest orchestrator executing the event loop step-by-step.
- **`app/api/routes.py`**: REST API endpoints (`/api/v1/backtest/run`, `/api/v1/data/symbols`, `/api/v1/data/preview`).
- **`tests/`**: Unit and integration test suite covering event bus routing, strategy signaling, backtest execution, and API responses.

### B. Frontend Web Application (Next.js 14, TypeScript & Tailwind CSS)
- **Glassmorphism Design System**: Custom CSS variables, subtle backdrop blurs, dynamic glow effects, and modern dark mode styling (`globals.css`).
- **Sticky Glass Navbar (`components/Navbar.tsx`)**: Navigation bar with live backend health status indicator.
- **Overview & Preset Launcher (`app/page.tsx`)**: Quick-start dashboard with one-click backtest triggers for standard moving average configurations.
- **Visual Strategy Builder (`components/VisualBuilder.tsx` & `app/builder/page.tsx`)**: Interactive canvas built with React Flow (`@xyflow/react`) allowing drag-and-drop rule wiring (Data Source $\rightarrow$ Fast MA $\rightarrow$ Slow MA $\rightarrow$ Execution Engine).
- **Analytics Dashboard (`components/PerformanceDashboard.tsx` & `app/backtests/[id]/page.tsx`)**:
  - Interactive **Recharts** equity curve visualization.
  - KPI metric cards with performance color indicators.
  - Filterable trade log table with CSV export capabilities.

### C. Infrastructure & Containerization
- **`backend/Dockerfile`**: Python 3.10 slim container environment.
- **`frontend/Dockerfile`**: Node.js 18 alpine build container environment.
- **`docker-compose.yml`**: Multi-container orchestration linking backend (`port 8000`) and frontend (`port 3000`).
